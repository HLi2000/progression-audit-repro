# Progression-Audit — TAE paper (self-contained LaTeX project)

Submission-ready NeurIPS-style paper for the NeurIPS 2026 workshop **TAE — "Can We Trust AI Evaluation?"**:
*The Camera, the Split, and the Label: A Three-Check Audit of Glaucoma-Progression Prediction.*
This directory is **self-contained** — it carries its own style files, bibliography, and figures.

## Build locally
```bash
tectonic -X compile main.tex   # -> main.pdf  (install: `brew install tectonic` or `cargo install tectonic`)
# or: make                     # pdflatex + bibtex, if a system TeX is installed
```

Body is ~8 pp (title→conclusion); references + appendix follow. Anonymous submission mode (line numbers,
"Anonymous Author(s)"). For camera-ready, switch `[dblblindworkshop]{neurips_2026}` to `[final]{neurips_2026}` and
de-anonymize the author block in `main.tex`.

## Files
- `main.tex` — preamble + document skeleton (inputs the parts below)
- `sections.tex` — abstract → conclusion
- `table1.tex` — the prior-claims audit map (hand-curated headline table)
- `appendix.tex` + `appendix_tables.tex` — setup, cohort card, full reproduce-collapse + honest-representation +
  endpoint-sensitivity tables, reproducibility + broader impact
- `references.bib` — verified bibliography (see `REFERENCES_VERIFICATION.md`)
- `figures/` — vector PDFs, regenerated by `scripts/build_progression_audit_figures.py` (repo root); no re-scoring,
  driven by the committed `reports/progression_audit_panel.json`
- `neurips_2026.sty`, `extra_pkgs.tex`, `Makefile` — style + build

## Regenerate the data panel, figures, and tables

Run from the repository root — see the top-level [`README.md`](../../README.md) for the full quickstart:

```bash
cd ../..                                                    # repository root
uv run python scripts/build_progression_audit_panel.py      # -> reports/progression_audit_panel.json (reconciled)
uv run python scripts/build_progression_audit_figures.py    # -> papers/progression-audit-tae/figures/*.{pdf,png}
uv run python scripts/build_progression_audit_tables.py     # -> papers/progression-audit-tae/appendix_tables.tex
```
Every number in the paper traces to `reports/progression_audit_panel.json`; the panel builder's reconciliation gate
cross-checks each headline constant against the committed `data/derived/grape_*` artifacts (no re-scoring).
